# Faculty Portal

Faculty Portal is a Java and MySQL-based management system designed to simplify interaction between students, faculty members, and administrators. The application provides secure login functionality, role-based dashboards, and database-driven record management.

## Features
- User Authentication System
- Student Dashboard
- Faculty Dashboard
- Admin Dashboard
- MySQL Database Integration
- Faculty and Student Management
- Role-Based Access Control

## Technologies Used
- Java
- MySQL
- JDBC
- Object-Oriented Programming

## Project Objective
The goal of this project is to provide a centralized platform for managing academic users and improving communication and accessibility within an educational institution.
